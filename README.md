# Social Links Profile Card

Este es un proyecto de práctica de frontend creado como parte de un reto de [Frontend Mentor](https://www.frontendmentor.io/). El desafío consistía en replicar un diseño específico solo utilizando **HTML** y **CSS**.

## 🖼️ Descripción

La página consiste en una **card de perfil** que muestra:
- Una imagen de perfil
- Mi nombre y ciudad
- Una pequeña biografía
- Botones con enlaces a mis redes sociales

Es un diseño simple y limpio, ideal para practicar el uso de **Flexbox**, diseño responsive y estilos modernos.

## 💻 Tecnologías utilizadas

- HTML5
- CSS3 (con Flexbox)
- Google Fonts

## 📱 Responsive

El diseño es responsive y se adapta a distintos tamaños de pantalla, incluyendo dispositivos móviles con pantallas desde **320px** de ancho.
